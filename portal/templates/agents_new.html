Build an agent

An agent here is a model with instructions, skills, MCP servers and data, and no code of its own: the platform's runtime runs it. You write its instructions in the portal, and pick its skills, MCP servers and data on its app page, per environment, as for any app.

1. Create the repo

Create your agent's repository from the platform's template, named agent-<name> in lower-case letters, digits and -.

Use this template

Then ask the platform team to add it to the portal's read App and agent App. The portal finds the repo on the collector's next pass.
