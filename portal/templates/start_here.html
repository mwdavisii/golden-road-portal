Golden road

Start here

The golden road packages an app so that it can be deployed, checked and reviewed the same way every time.

  1. Before you start

    • You can read {{ settings.org }}/golden-road-agents on {{ settings.github_host }}. Open the link: if you see the repository, you're set. If not, ask the platform team for access.
    • Install uv, the Python tool the skill uses to install the builder:
      • macOS: brew install uv
      • Windows: winget install --id=astral-sh.uv -e
      • Linux, or macOS without Homebrew: curl -LsSf https://astral.sh/uv/install.sh | sh
      Then open a new terminal and check that uv --version prints a version. Other ways to install it are in uv's installation guide.
    • Sign in to GitHub with gh auth login --hostname {{ settings.github_host }}.
